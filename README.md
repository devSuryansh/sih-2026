# SIH 2026

Three Smart India Hackathon 2026 demo projects, one per theme (problem statements from https://sih.gov.in/sih2026PS).

| Theme | PS id | Project (submodule path) |
|---|---|---|
| Disaster Management | SIH26085 | `projects/sih26085-urban-flood-nowcast` |
| Blockchain & Cybersecurity | SIH26183 | `projects/sih26183-crypto-fraud-tracer` |
| Smart Automation | SIH26108 | `projects/sih26108-is-standards-recommender` |

## Clone
```
git clone --recurse-submodules https://github.com/devSuryansh/sih-2026.git
```
If already cloned: `git submodule update --init --recursive`.

Each project's README has run instructions. All data is synthetic/sample.
